## 三、必须知道的机制（踩过的坑）

1. **最上层顶栏只有 3 格：`菜单 / 笔记 / 离开`** —— 最右那个是**退出游戏**。
   深层页面才有「返回」。**已因此把游戏点退 3 次。**
   - 判据：`b2.Count -le 3` 就是最上层，别点最右

2. **课程是分页的，必须翻完所有页才算完成。**
   - 翻页按钮在顶栏第 2 格：`s028`=下一页、`s027`=上一页
   - **翻页后第二页里的未知数要自己算出来写进译文栏**，否则课程不算真做完
   - 完成判据：列表条目由 **white（`Tone=white`，亮度≈187）** 变 **gray（≈83）**

3. **判断前先把鼠标移开**（`SetCursorPos 100,300`），否则残留高亮会让人误判行列颜色。

4. **写译文后必须重新截图确认**：`Set-GameTranslation` 返回成功 ≠ 屏幕已刷新。
   页面上的 `?` 变成数字/中文才算成功。

5. **合并格写不进去**：一个 160px 格子里塞了两个符号时（如 `日日`、`区∧`），
   写到该格译文栏游戏不认。用 `-Index` 换一个单独渲染的位置。

6. **`page-dump` 的 `[空]` 不可全信**：Crop 识别只支持单字，`14`/`21`/`28` 这类多字符会误判为空。
   怀疑时用 `Get-GameTranslationText -SymbolId <id>`（剪贴板法）精确读一次。

7. **一句话一半以上是问号就别死磕** —— 换别的页面。

## 四、数字体系

**7 进制**：顶横是 ×7 进位标记，下方竖线是计数。

| 形状 | 值 |
|---|---|
| `T`（1 横 1 竖） | 7 |
| `TT`（1 横 2 竖） | 14 |
| `TTT`（1 横 3 竖） | 21 |
| 顶横 + 十字 | 28 |
| 双横 1 竖 | 49 |
| 双横 2 竖 | 98 |
| 双横 3 竖 | 147 |
| 三横 1 竖 | 343 |

**小于 7 的数**：竖线计数（`|`=1、`||`=2、`|||`=3）、十字=4、井=5、密井=6。
**组合写法**：`7 1` = 8、`7 2` = 9、`7 5` = 12（即 7 + 余数）。
