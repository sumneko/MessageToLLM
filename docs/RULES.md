# 协作规则（对人 / 对 AI）

> 这三条优先级高于任何「顺手做的事」。

1. **提问先回答**
   用户提问时，先直接给答复。不要借机开工、不要顺手改代码、不要先写长方案。

2. **大规模写代码要先获批**
   下列动作视为「大规模写代码」，必须先取得明确许可：
   - 重构、改插件（`tools/probe-inject/`）、改接口语义
   - 连续多轮「改代码 → 编译 → 重启游戏」的验证循环
   - 新增命令/脚本/文档章节

   单点小改动（用户明确指出的那一行、那一条命令）按指示直接做。

3. **禁止擅自展开**
   - 不加没被要求的功能
   - 不动无关文件
   - 不擅自扩大范围（包括「顺便优化」「顺便清理」）
   - 需要调查或设计时，先给结论 + 一句话方案，等许可再执行
